# l4cEnvironmentCore — "Entorno Sonoro" v2.3

**Addon:** Lost 4 Creed — Environmental Audio  
**Author:** Lost 4 Creed Team  
**Entry Point:** Ninguno (solo assets de audio)  
**Dependencias:** Ninguna  
**Tamaño:** ~200+ archivos WAV

---

## 📋 Descripción

Addon puramente de audio que reemplaza y expande los paisajes sonoros del entorno en Left 4 Dead 2. Incluye ambientes, clima, naturaleza, sonidos espaciales, alarmas, y música de campaña.

Sin scripts VScript — solo archivos de sonido.

---

## 📂 Estructura

```
sound/
├── ambient/
│   ├── alarms/              ← Sonidos de alarma
│   ├── ambience/            ← Loops de ambiente general
│   ├── atmosphere/          ← Atmosferas
│   ├── nature/              ← Sonidos de naturaleza
│   ├── overhead/            ← Sonidos overhead
│   ├── random_amb_sfx/      ← Efectos aleatorios de ambiente
│   ├── spacial_loops/       ← Loops espaciales
│   ├── weather/             ← Clima (lluvia, viento, tormentas)
│   └── wind/                ← Viento
├── music/
│   ├── contagion/           ← Temas de Contagion
│   ├── cpmusic/             ← Música por campaña:
│   │                         Blood Harvest, Crash Course, Dead Air,
│   │                         Death Toll, No Mercy, etc.
│   ├── glimpse/             ← "A Glimpse of Death/Hell"
│   └── mob/                 ← Temas de horda por campaña:
│                             deadlightgerm, easygerm, fairgroundgerm,
│                             mallgerm, milltowngerm, parishtmptgerm,
│                             plankgerm
```

---

## 🎵 Contenido por Categoría

### Ambiental

| Carpeta | Propósito |
|---------|-----------|
| `ambient/alarms/` | Alarmas de edificios y coches |
| `ambient/ambience/` | Loops base de ambiente |
| `ambient/atmosphere/` | Atmosferas densas |
| `ambient/nature/` | Sonidos naturales (aves, insectos, agua) |
| `ambient/weather/` | Clima dinámico |
| `ambient/wind/` | Viento ambiental |

### Música por Campaña

Los temas de horda varian según la campaña para dar identidad sonora única a cada mapa.
