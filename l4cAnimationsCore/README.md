# l4cAnimationsCore — "Núcleo de Animaciones" v2.3

**Addon:** Lost 4 Creed — Animation Core  
**Author:** Lost 4 Creed Team  
**Entry Point:** Ninguno  
**Dependencias:** **XDReanims** (mod externo requerido)

---

## 📋 Descripción

Addon placeholder que documenta la dependencia de **XDReanims** para el modpack. No contiene archivos de animación propios — solo existe para registrar la dependencia.

**Requiere el mod externo:** `xdReanimsBase_(L4D2)_Anim_Mods_base_[ID].vpk`

---

## 📂 Estructura

```
l4cAnimationsCore/
└── addoninfo.txt
```

Sin scripts, sin materiales, sin modelos. Solo el archivo de metadatos del addon.

---

## 🎯 Propósito

1. **Documentar** la dependencia de XDReanims para otros desarrolladores
2. **Registrar** en el sistema de addons que Lost 4 Creed requiere animaciones personalizadas
3. **Prevenir** errores de carga si XDReanims no está instalado

---

## 🔧 Dependencias

| Mod | Relación |
|-----|----------|
| XDReanims Base | **REQUERIDO** — Provee el sistema de animaciones |

---

## ⚠️ Notas

- Este addon no contiene animaciones — es un placeholder
- Las animaciones reales las provee `xdReanimsBase`
- Sin XDReanims, las animaciones del juego base se usarán por defecto
